
# C Programming

Мои учебные работы по программированию на языке C.

Здесь собраны лабораторные работы, небольшие программы и задания по работе с файлами, указателями и другими возможностями C.

## Лабораторные работы

### Первый семестр

Исходники находятся в папках `lb1`–`lb12`.

### Второй семестр

Работы находятся в папке [1.0 Term2](1.0%20Term2/).

## Дополнительные материалы

В репозитории также находятся программы для сортировки и отчёты по учебным заданиям.

## Компиляция

Для простой программы на C:

```bash
gcc main.c -o main
./main
```

Название исходного файла зависит от выбранной лабораторной работы.
